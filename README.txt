СЫЧИНАЯ ОХОТА - VK BOT V4 AUTO ADD

Новое поведение:

1. Пользователь тегает бота в общей беседе:
   @Робосычик 30, 17

2. Бот получает VK ID, имя и фамилию профиля.

3. Если человек уже есть в листе "Участники":
   VK ID автоматически привязывается.

4. Если такого имени вообще нет:
   бот автоматически добавляет нового человека в лист "Участники",
   записывает его VK ID и добавляет его в текущую неделю.

5. Затем сохраняются план и факт.

ВАЖНО:
Если найдено несколько одинаковых имен, бот не выбирает человека наугад.
Автоматическое добавление происходит только когда совпадений нет вообще.

Новые участники не удаляются при последующих вызовах getParticipantsSheet().

ОБНОВЛЕНИЕ:
- заменить Code.gs;
- снова вписать SITE_PASSWORD;
- создать новую версию Web App;
- заменить app.py в GitHub;
- дождаться нового Deploy Render.


V5 - ДИНАМИЧЕСКОЕ КОЛИЧЕСТВО УЧАСТНИКОВ

Количество участников больше не зашито как 102.

Скрипт считает фактическое количество непустых имен в листе "Участники".

Дополнительные мыши:
(цель команды - суммарный план) / фактическое количество участников
с округлением вверх.

Если бот автоматически добавляет 103-го участника:
- в статистике peopleCount становится 103;
- расчет "добавить к плану на человека" сразу делится на 103;
- формула B6 текущего недельного листа обновляется автоматически.

Если участников станет 104, 105 и т.д., ничего в коде менять не нужно.

ОБНОВЛЕНИЕ:
1. Заменить Code.gs в Apps Script.
2. Вписать текущий SITE_PASSWORD.
3. Создать новую версию Web App deployment.
4. app.py можно заменить файлом из архива, но логика VK-бота относительно v4 не менялась.
