# Полный переход с Apps Script на Python

Статус: черновик, НЕ развёртывать. Прежний план общей блокировки с Apps Script
отменён. Не выполнять confirmOwletSharedWriteReady и не устанавливать
SharedWriteLock.gs / StatisticsEntrypoints.gs / ArtifactsEntrypoints.gs.

Итоговая схема: сайт и VK → Python → Google Sheets API и VK API.
Таблицы сохраняются. Apps Script, его Web App deployments и триггеры
после проверенного переключения перестают участвовать в работе.

## Недостающие исходники

Предоставленные «Сычиная_охота.gs» и «Робосычик_Дайджесты.gs» НЕ содержат
реализацию Quest API и отдельного API сокровищницы. Нужны:

1. Все .gs-файлы проекта, указанного в QUEST_SCRIPT_URL.
2. Все .gs-файлы проекта, который обслуживает TREASURY_API в treasury.js.
3. Для сохранения расписания — текущий список триггеров проектов: функция,
   дни/время и часовой пояс. В исходниках могут быть установщики триггеров,
   но они не доказывают, какие триггеры сейчас включены вручную.

Пароли, токены и private_key не присылать. Состояния и таблицы квестов
нельзя угадывать или сбрасывать при переносе. Получение недостающих исходников
не является согласием отправлять тестовые сообщения или перезаписывать живые данные.

## Уже подготовлено

В черновике есть прямые API участников, текущей записи и сохранения отчёта,
атомарная запись отчёта вместе с requestId, журнал выпадений, сохранение
инвентаря вместе с результатом броска, уведомление VK без недели и повтор
с постоянным random_id. Клиент сохраняет requestId при потере ответа.

Запись выключена двумя настройками: WEBSITE_WRITE_ENABLED и
NATIVE_STORAGE_ENABLED. Обе остаются false до полного переключения всех
писателей таблиц на Python. Проверка readiness из Apps Script удалена.
Блокировка Google Sheets между Python workers не требует Apps Script;
при неизвестном результате Google она сохраняется до проверки оператором.

## Порядок перехода

1. Завершить все перечисленные адаптеры и перенос расписания, покрыть тестами.
2. Сохранить резервные копии таблиц и текущих развёртываний.
3. Согласовать финальный diff и окно переключения с владельцем.
4. Приостановить старые писатели и Google-триггеры, дождаться завершения запросов.
5. Развернуть Python с нативными обработчиками сайта, VK, квестов и расписания.
6. Проверить согласованный отчёт, повтор того же запроса, синхронизацию,
   сокровищницу, квесты и уведомления. Проверить сохранение старых состояний.
7. Опубликовать сайт без ссылок на script.google.com.
8. Подтвердить отсутствие обращений к старым Web App и отключить deployments.
