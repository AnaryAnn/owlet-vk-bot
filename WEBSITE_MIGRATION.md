Сначала согласовать обновление работающих Apps Script и бота с владельцем.

   Существующее чтение статистики сохраняет readonly scope; запись использует отдельную сессию.
2. Сохранить резервные копии обоих Apps Script. Не публиковать их пароли в GitHub.
3. В проекте статистики переименовать исходные `doGet` и `doPost` в
   `owletLegacyGet` и `owletLegacyPost`; добавить `migration/SharedWriteLock.gs`
   и `migration/StatisticsEntrypoints.gs`.
4. В проекте дайджестов переименовать исходные `doPost` и
   `runWeeklyArtifactBonus_` в `owletLegacyPost` и `owletLegacyWeeklyArtifactBonus_`;
   добавить общий файл блокировки и `migration/ArtifactsEntrypoints.gs`.
5. Разрешить вызовы Google Sheets API из обоих Apps Script. При явно заданных OAuth scopes
   нужны `https://www.googleapis.com/auth/spreadsheets` и
   `https://www.googleapis.com/auth/script.external_request`; существующие scopes сохранить.
   Sheets API должен быть включён в связанных Google Cloud проектах.
6. Опубликовать новые версии ОБОИХ Web App, сохранив URL. Убедиться, что
   все пишущие Web App deployments используют обёртки; старые deployments отключить.
   Выполнить `confirmOwletSharedWriteReady` вручную в каждом проекте только после этого.
   Не запускать ручные `setup`/`migrateOldData` и не редактировать строки таблиц
   одновременно с записью сайта. Другие скрипты, пишущие в эти таблицы,
   также должны использовать общую блокировку.

## Включение

1. Развернуть PR бота, сохранив `WEBSITE_WRITE_ENABLED=false`.
   Бот продолжает работать прежним способом. API чтения не меняет права.
   В существующей команде Gunicorn увеличить `--timeout` и `--graceful-timeout`
   как минимум до 180 секунд, сохранив остальные параметры. Типовой пример:
   `gunicorn --timeout 180 --graceful-timeout 180 app:app`.
   По умолчанию worker может быть остановлен посреди медленного запроса Google;
   тогда общая блокировка намеренно потребует ручной проверки.
2. После проверки обёрток установить `WEBSITE_WRITE_ENABLED=true` в Render.
   `STATS_SPREADSHEET_ID` и `ARTIFACTS_SPREADSHEET_ID` можно задать явно;
   значения по умолчанию соответствуют двум таблицам владельца.
3. Проверить один согласованный отчёт на реальной таблице и уведомление в беседе
   `2000000002`. Повторить тот же `requestId`: данные, награда и сообщение не дублируются.
4. Только после успешной проверки опубликовать связанный PR сайта.

## Гарантии и границы

Идентификатор запроса сохраняется в браузере до подтверждения всех этапов.
Отчёт и журнал `_WebsiteReports` записываются одним атомарным batchUpdate.
Повтор requestId с другим содержимым отклоняется. При неизменённых данных
новое уведомление не отправляется. Бросок возможен только при увеличении факта:
10% при факте ниже плана, 20% при выполнении плана. Редкости: 65/22/9/3/1.
Инвентарь и результат броска `_ArtifactDrops` записываются атомарно.
VK получает постоянный random_id для повтора одного сообщения.

Это защита в пределах срока дедупликации VK, а не бесконечная гарантия exactly-once
между внешними сервисами. При неизвестном результате отправки повтор выполняется
тем же requestId. Если отложенная отправка не подтверждена, сайт показывает
предупреждение и сохраняет идентификатор для повторного нажатия.
Постоянного фонового обработчика нет: незавершённые операции возобновляются
повтором запроса пользователем.

Новая неделя и строка участника должны быть созданы существующей синхронизацией.
API записи не создаёт их сам и не восстанавливает INITIAL_PEOPLE.
Вход, административная цель и сокровищница остаются на прежних API;
список участников, текущая запись, запись отчёта и артефакт за неё идут напрямую.

## Неопределённый результат Google

Общий замок — DOCUMENT developer metadata с ID `1937152401`, ключом
`owlet_shared_write_v1`. Уникальность ID обеспечивается Google Sheets.
Он намеренно не протухает. При timeout/5xx записи Python оставляет замок:
иначе поздняя запись могла бы перезаписать более новую. Нужно остановить запись,
дождаться завершения всех старых запросов, проверить журнал и данные,
а затем вручную удалить именно эти метаданные через Sheets API.
Не удалять readiness metadata `1937152402` для восстановления замка.
Не добавлять автоматический takeover по времени без механизма fencing.

## Откат

Сначала вернуть предыдущую версию сайта, затем отключить `WEBSITE_WRITE_ENABLED`.
Журналы и выданные артефакты не удалять. Обёртки блокировок можно оставить:
они сохраняют существующую логику отчётов VK. Возврат старых Web App без обёрток
допустим только после отключения новых Python-записей и завершения запросов.

Проверки: `PYTHONPATH=. python -m unittest discover -s tests -v`;
связанный сайт: `node tests/statistics.cjs` и `node tests/records.cjs`.
